# M5. Sessiyalar, xavfsizlik, audit

Autentifikatsiyani mustahkamla (backend va "Xavfsizlik" sahifasi).

BACKEND:
- Qurilma sessiyalari: har refresh token uchun metadata (qurilma/brauzer, IP, oxirgi faollik). GET /me/sessions/, DELETE /me/sessions/{id}/, joriy sessiyadan tashqari hammasini tugatish.
- Refresh rotation reuse detection: eski token qayta ishlatilsa butun oilani bekor qil.
- Xavfsizlik xatlari: yangi qurilmadan kirish, parol o'zgarishi, yangi usul bog'langani.
- GET /me/security-log/ (oxirgi 50 AuthEvent).
- Throttle sozlamalari env orqali; django check --deploy xatosiz; security headerlar.
- Foydalanuvchini bloklash/blokdan chiqarish (is_active) va tokenlarini bekor qilish xizmat funksiyasi (admin API keyin ishlatadi).
- Logga parol, token, OTP yozilmasin (structlog processor).
Testlar: reuse detection, sessiyani tugatish, bloklangan foydalanuvchi tokeni ishlamasligi, log'da maxfiy ma'lumot yo'qligi. make schema.

FRONTEND:
- make types. Sozlamalar → Xavfsizlik: faol qurilmalar ro'yxati (joriy qurilma belgisi, "Chiqish" va "Boshqa hamma qurilmadan chiqish"), xavfsizlik jurnali (oxirgi kirishlar), parol almashtirish.
- Bloklangan yoki bekor qilingan sessiya aniqlansa: tushunarli xabar bilan /kirish ga yo'naltirish.
Testlar: komponentlar va refresh-reuse holatida frontend xatti-harakati. Playwright: ikki sessiya, birini boshqasidan tugatish.
Tayyor mezoni bo'yicha yakunla.
