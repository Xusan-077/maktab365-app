# M7. Ochiq kontent API + qidiruv + frontend kontentni API'dan oladi

Ochiq kontent API (backend) va frontend sahifalarini haqiqiy ma'lumotga o'tkazish.

BACKEND (login talab qilmaydi, faqat published):
- GET /api/v1/grades/, /subjects/?grade=, /books/?grade=&subject=&q=&topics_ready= (sahifalangan), /books/{slug}/ (boblar+mavzular ro'yxati, bloklarsiz), /books/{book}/topics/{topic}/ (to'liq blocks, oldingi/keyingi mavzu, breadcrumb), /search/?q=&grade=&subject=.
- Til: ?locale= yoki Accept-Language; LocalizedText to'liq obyekt qaytadi (fallback frontendda).
- Qidiruv: PostgreSQL full-text (uz/ru/en uchun konfiguratsiya yoki 'simple'+pg_trgm), search_vector signal/trigger bilan yangilanadi, snippet qaytaradi. Kirill so'rov lotinga translit qilib ham qidiriladi (apps/core/translit.py: frontend funksiyasining Python varianti, ikkala tomonda umumiy test vektorlar contracts/fixtures/translit.json).
- Kesh: Redis, kontent versiyasiga bog'liq kalit; ETag/If-None-Match; publish bo'lganda tozalanadi; Cache-Control qisqa max-age.
- Staff (editor/admin) draft/reviewed mavzularni ham ko'ra oladi; ochiq API'da status != published bo'lsa chiqmaydi, lekin sozlama SHOW_DRAFTS_PUBLICLY=true bo'lsa "unverified: true" flag bilan chiqadi (frontend "Tekshiruvdan o'tmagan" belgisi shunga bog'lanadi).
- N+1 yo'q (django_assert_max_num_queries bilan testlar). OpenAPI to'liq.
Testlar: filtrlar, faqat published, qidiruv (lotin/kirill), kesh invalidatsiyasi, unverified flag. make schema.

FRONTEND:
- make types. HttpApi: getGrades, getSubjects, getBooks, getBook, getChapters, getTopic, searchTopics haqiqiy API'dan. Server komponentlarda Next fetch keshi (revalidate + tag), mavzu sahifasi ISR.
- Katalog, fan, kitob, mavzu, bosh sahifadagi fanlar kartochkalari, qidiruv (topbar va marketing) NEXT_PUBLIC_API_MODE=http da backend ma'lumotini ishlatsin. Qidiruv natijasida snippet ko'rsatilsin.
- "Tekshiruvdan o'tmagan" belgisi backend'dagi unverified flag'idan.
- Backend o'chiq/xato bo'lsa tushunarli xato sahifasi va qayta urinish tugmasi.
- Eski mock kontent faqat mock rejimida qoladi.
Playwright e2e (haqiqiy backend + import qilingan kontent): bosh sahifa → katalog filtr → kitob → mavzu → mashq; qidiruv lotin va kirill.
Tayyor mezoni bo'yicha yakunla.
