# M1. Backend poydevori + frontend API ulanish asosi

Backend poydevorini (backend/ ichida) va frontendning API ulanish asosini birga qur.

BACKEND (backend/): bitta Django monolit.
Stack: Python 3.12, uv, Django 5, djangorestframework, drf-spectacular, djangorestframework-simplejwt, django-environ, django-cors-headers, psycopg[binary], celery+redis, argon2-cffi, django-storages, sentry-sdk, structlog, pytest, pytest-django, pytest-xdist, factory-boy, ruff, pre-commit.
Tuzilma: config/settings/{base,dev,prod,test}.py (env orqali), config/{urls,celery,asgi,wsgi}.py, apps/{core,accounts,content,learning,support,analytics} (core to'ldiriladi, qolganlari bo'sh ilova), Dockerfile, .env.example, backend/CLAUDE.md, README.
Ildizdagi docker-compose.yml: postgres, redis, backend (hot reload), worker. Ildiz Makefile target'larini haqiqiy buyruqlar bilan to'ldir (make dev, test, lint, migrate, schema).
apps/core (qayta ishlatiladigan poydevor):
- UUIDModel, TimeStampedModel, SoftDeleteModel.
- LocalizedTextField (JSONField asosida; kalitlar faqat uz/ru/en; uz majburiy).
- Permission'lar: IsRole(...), IsOwner, ReadOnlyOrStaff. Yagona xato handler ({code,message,details}), pagination, throttle sinflari, filter backend.
- /api/v1/health/ (db va redis), /api/schema/, /api/docs/ (Swagger, faqat dev).
- Request-id middleware, structlog JSON log, Sentry (env bo'lsa), prod xavfsizlik sozlamalari, CORS faqat env'dagi frontend origin.
- `make schema` backend/openapi.yaml ni yozadi.
CI: backend job (ruff, pytest, migrations check, schema'ning commit qilingan nusxadan farqini tekshirish).

FRONTEND (frontend/):
- openapi-typescript va openapi-fetch o'rnat. `npm run api:types` backend/openapi.yaml dan src/lib/api/schema.ts ni generatsiya qiladi (make types shuni chaqiradi).
- src/lib/api/http-client.ts: typed klient, base URL env'dan (NEXT_PUBLIC_API_URL brauzer uchun, API_URL server uchun), xato formatini ApiError sinfiga aylantiradi, so'rov id va timeout.
- HttpApi skeleti (MaktabApi interfeysini implement qiladi; hozircha faqat health(), qolgan metodlar "keyingi bosqichda" xatosi bilan). NEXT_PUBLIC_API_MODE=mock|http almashtirgichi saqlansin.
- /dev/api-status (faqat dev): backend /health/ holatini ko'rsatadi.
- .env.example yangila.

Tekshiruv: make dev dan keyin /dev/api-status backend "ok" ko'rsatadi. Bosqich tayyor mezoni (CLAUDE.md) bo'yicha yakunla.
