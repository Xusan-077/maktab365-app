# M11. Mavzu muharriri + versiyalar tarixi

Admin'ning eng muhim qismi: mavzu muharriri.

BACKEND:
- PUT /admin/topics/{id}/ (blocks validatsiya bilan: xato aniq blok va maydonni ko'rsatsin), har saqlashda TopicRevision, GET /admin/topics/{id}/revisions/, POST .../revisions/{rev}/restore/.
- Optimistik bloklash: updated_at/ETag bilan (ikki editor bir mavzuni bir vaqtda tahrirlasa, ikkinchisiga to'qnashuv xatosi va farqni ko'rsatish uchun joriy versiya qaytadi).
- Widget kind'lar ro'yxati va har birining props sxemasi uchun GET /admin/widgets/ (forma generatsiyasi uchun JSON Schema).
Testlar: validatsiya xatolari, revision, to'qnashuv, restore. make schema.

FRONTEND:
- make types. Muharrir sahifasi: chap — blok ro'yxati (7 tartibli bloklar, qo'shish/o'chirish/surish), o'rta — tanlangan blok formasi (goal, tushuntirish, qoida, misol qadamlari, mashq turlari choice/input/truefalse, hint, explanation, widget tanlash va props formasi JSON Schema'dan), o'ng — jonli preview (haqiqiy TopicRenderer, KaTeX, til almashtirgich uz/Кирилл/ru/en).
- Avto-saqlash qoralamasi (localStorage) va aniq "Saqlash"; server validatsiya xatosi tegishli blokda ko'rsatiladi; to'qnashuvda "Boshqa editor o'zgartirdi" dialogi (qayta yuklash yoki o'zimnikini saqlash).
- Versiyalar tarixi paneli: ro'yxat, farq ko'rish (oddiy), qaytarish.
- Saqlanmagan o'zgarish bilan chiqishda ogohlantirish.
Testlar: blok qo'shish/o'chirish/surish, validatsiya xatosini ko'rsatish, to'qnashuv. Playwright: mavzu yozish → saqlash → revision'dan qaytarish.
Tayyor mezoni bo'yicha yakunla.
