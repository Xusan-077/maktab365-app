# M15. Sifat, deploy, xavfsizlik

Ikkala tomonni ishga tayyorla.
BACKEND:
- Testlar: umumiy qamrov >= 85%, kritik joylar (auth, merge, ruxsatlar) to'liq yo'llar bilan. Yuk testi skripti (k6 yoki locust) repoda; asosiy ochiq endpointlarda so'rov soni tekshiruvlari, kerakli indekslar (EXPLAIN bilan).
- Docker: ko'p bosqichli Dockerfile, gunicorn (uvicorn worker), healthcheck, non-root. docker-compose.prod.yml namunasi (backend, worker, beat, postgres, redis, reverse proxy Caddy/nginx).
- Migratsiya va deploy tartibi, kunlik pg_dump zaxirasi va tiklash yo'riqnomasi.
- Kuzatuv: Sentry, JSON log, /health/. Xavfsizlik: bandit, pip-audit, django check --deploy.
FRONTEND:
- Lighthouse mobile >= 90 (home, katalog, mavzu) haqiqiy backend bilan; a11y (axe-core) tekshiruvi; Sentry (env bo'lsa); sitemap.xml mavzularni backend'dan oladi; OpenGraph/JSON-LD mavzu ma'lumotidan.
- npm audit, bog'liqliklar yangilash.
UMUMIY:
- Ildizda to'liq e2e: make e2e noldan docker compose bilan ko'taradi, kontent import qiladi, asosiy yo'llarni (mehmon, kirish usullari, o'quvchi, o'qituvchi, editor nashr oqimi, admin) Playwright bilan o'tadi. CI'da ham ishlasin (kamida smoke to'plam).
- Ildiz README: noldan ishga tushirish, ilovalar xaritasi, yangi ilova qo'shish (poydevorni boshqa loyiha uchun qayta ishlatish bo'limi), yangi kirish usuli qo'shish, deploy (Vercel Root Directory=frontend; backend uchun server), env jadvali (ikkala tomon).
Topilgan muammolarni tuzat. Oxirida hammasi yashil va README bo'yicha noldan sinab ko'r.
