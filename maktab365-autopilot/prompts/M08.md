# M8. O'qish jarayoni: progress, xatcho'p, reja, merge + kabinetlar

apps/learning (hammasi login talab qiladi) va kabinetlarni haqiqiy API'ga ulash.

BACKEND:
Modellar: TopicProgress (user, topic, read_status not_started|in_progress|read, exercise_status not_started|in_progress|passed, last_block_id, scroll_position?, mistakes JSON [{exercise_id, attempts, last_wrong_at}], exercise_stats, first_opened_at, read_at, passed_at, updated_at; unique(user, topic)), Bookmark (user, kind book|topic, book/topic FK; unique), StudyGoal (user, title, topic?, due_date?, done_at), RecentView (oxirgi 20 ta).
Endpoint'lar (/api/v1/me/): GET/PUT progress/{topic_id}/ (PUT idempotent, monoton: holat pasaymaydi, last_block_id yangiroq updated_at niki), GET progress/ (filtr), POST events/ (topic_opened, topic_read, exercise_answered{exercise_id, correct}), GET/POST/DELETE bookmarks/, GET recent/, CRUD goals/, GET dashboard/ (continue, fanlari, takrorlash kerak, haftalik natija, saqlanganlar soni), GET results/ (mavzu kesimida yaxshi o'zlashtirilgan va takrorlash kerak; "o'qidim" va "mashqdan o'tdim" alohida), GET teacher/dashboard/, POST merge-guest-data/ (idempotent, hajm limiti 500; qoidalar frontenddagi merge-guest-data.ts bilan bir xil: holatlar eng yuqorisi, xatolar birlashmasi, last_block_id yangiroq yozuvniki).
"Takrorlash kerak" mantig'i services/review.py. 
Testlar: monoton progress, idempotentlik, merge holatlari (ikki tomon uchun umumiy fixture contracts/fixtures/merge-*.json), begona ma'lumotga kirish taqiqi, dashboard shakli. make schema.

FRONTEND:
- make types. Kirgan foydalanuvchi uchun progress/events, bookmarks, goals, recent haqiqiy API'dan, TanStack Query optimistic update + rollback; offline/sekin internetda yozuvlar navbatga tushadi va qayta uriniladi. Mehmon rejimi o'zgarmaydi (Zustand persist).
- Birinchi kirishdan keyin merge: POST /me/merge-guest-data/ (idempotent); muvaffaqiyatda guest.store tozalanadi, xatoda saqlanib keyin qayta uriniladi.
- /kabinet (bosh, natijalar, saqlanganlar, fanlarim) va /ustoz sahifalari dashboard/results/teacher dashboard endpointlaridan. "Davom ettirish" last_block_id ga olib boradi. Katalog va kitob sahifasidagi "o'qilgan" belgilari serverdan.
Testlar: merge oqimi (muvaffaqiyat/xato/qayta urinish), optimistic rollback. Playwright: mehmon sifatida o'qish+xatcho'p → kirish → ma'lumot akkauntda; boshqa brauzerda kirib "davom ettirish".
