# M3. Email + parol autentifikatsiya (backend) + kirish/ro'yxatdan o'tish sahifalari

Email+parol kirishni to'liq (backend va frontend) qur. SimpleJWT: access 15 daqiqa, refresh 30 kun, rotation + blacklist.

BACKEND (/api/v1/auth/):
- POST register/ {email, password, display_name?}: akkaunt yaratadi (email_verified_at=null), tasdiqlash xati yuboradi, {access, refresh, user, is_new:true} qaytaradi. Tasdiqlanmagan foydalanuvchi ham kira oladi; me/ da email_verified flag.
- POST login/, POST refresh/, POST logout/ (refresh'ni blacklist), POST logout-all/.
- POST email/verify/ {token}, POST email/resend/ (cooldown 60s).
- POST password/forgot/ (har doim 200: akkaunt borligini oshkor qilma), POST password/reset/, POST password/change/ (boshqa refresh tokenlarni bekor qiladi).
- Tokenlar: VerificationToken (hash saqlanadi; tasdiqlash 24 soat, reset 1 soat, bir martalik).
- Xavfsizlik: login/register/forgot/resend uchun throttle (IP va email bo'yicha), ketma-ket xatolardan keyin vaqtinchalik bloklash (Redis), enumeration va timing farqidan himoya.
- Email Celery task orqali; dev: console backend, prod: SMTP/Resend (env). Shablonlar uz/ru/en (foydalanuvchi locale'iga qarab), toza HTML+text.
- Har hodisa AuthEvent'ga.
Testlar: butun oqim (register→verify→login→refresh→logout), noto'g'ri parol, throttle, token qayta ishlatilmasligi, muddati o'tgan token, enumeration. make schema.

FRONTEND:
- make types. src/auth.ts: Credentials provider "password" (POST /auth/login/ va register). jwt callback: backend access/refresh'ni saqla, muddati yaqinlashganda POST /auth/refresh/ bilan yangila, refresh xato bersa sessiyani tugat. session'ga user, role, onboarded, emailVerified qo'sh. getServerAccessToken() yordamchisi; HttpApi server so'rovlarida Bearer qo'shadi.
- Mavjud Google provayderini hozircha o'zgartirma (M4 da backend bilan ulanadi); ammo Google orqali kirganlar uchun vaqtincha eski oqim ishlashda qolsin (feature flag: NEXT_PUBLIC_BACKEND_AUTH=true bo'lsa yangi oqim).
- (auth) layout, minimal: /kirish — tablar "Kirish" va "Ro'yxatdan o'tish" (RHF+Yup, custom Input/Select, tushunarli o'zbekcha xatolar, 4 til i18n), ostida joy "Google bilan davom etish" (hozircha eski), "Kirmasdan davom etish" havolasi.
- /parolni-unutdim, /parolni-tiklash?token=, /email-tasdiqlash?token=.
- Email tasdiqlanmagan foydalanuvchiga panelda yengil banner (qayta yuborish tugmasi bilan), bloklamasdan.
- Proxy/middleware session maydonlariga tayansin (onboarded=false → /onboarding, rolga qarab /kabinet yoki /ustoz). Onboarding endi haqiqiy backend'ga yozadi (M2 dagi HttpApi).
- Sozlamalar → Xavfsizlik: parolni almashtirish.
Testlar: jwt callback (refresh), proxy yo'naltirishlari, forma validatsiyalari. Playwright e2e (docker compose backend bilan): register → onboarding → kabinet; logout; login.
Tayyor mezoni bo'yicha yakunla.
