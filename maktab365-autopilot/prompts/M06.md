# M6. Kontent modellari + import + frontend kontent validatsiyasi

Kontent poydevori (backend) va frontenddagi kontent fayllari bilan moslik.

BACKEND (apps/content, UUID, TimeStamped, matnlar LocalizedTextField):
- Subject (slug, title, icon, order). Book (slug, subject, grade 1–11, title, author, publisher, edition, year, cover, pdf?, topics_ready, order, is_published). Chapter (book, title, order). Topic (chapter, slug (kitob ichida unique), title, summary, blocks JSON, status draft|reviewed|published, reviewed_by/at, notes, order, published_at, search_vector keyin). TopicRevision (topic, blocks snapshot, title, author, comment, created_at; oxirgi 50 ta).
- Blocks validatsiyasi: frontenddagi TopicBlock sxemasi bilan bir xil (goal, explanation, rule, example(steps), exercise(choice|input|truefalse, options, answer, hint, explanation), summary, widget(kind, props)); pydantic (apps/content/schemas.py); xatoda aniq blok va maydon. Widget kind'lar: QuadraticGraph, GeometryPoints, ChoiceExplain, Timeline.
- Management command `import_content <papka>`: frontend/src/content/**/*.json (Algebra, Geometriya, Ingliz tili, Tarix) ni idempotent yuklaydi (slug bo'yicha upsert), status saqlanadi, `--dry-run`.
- Django admin: kitob/bob/mavzu inline, status filtri.
- Fayl saqlash: django-storages (S3-mos), dev'da local.
Testlar: sxema validatsiyasi (to'g'ri/noto'g'ri), import idempotentligi, revision. make schema.

FRONTEND:
- frontend/src/content sxemasi (Yup/Zod) backend pydantic sxemasi bilan 1:1 mos ekanini tekshiradigan test (ikkala tomonda umumiy namuna JSON fixture'lar: ildizda contracts/fixtures/topic-valid.json va topic-invalid-*.json; backend testlari ham, frontend testlari ham shularni ishlatadi).
- `npm run content:validate` hamon ishlaydi; `make import-content` ildizdan frontend kontentini backendga yuklaydi.
- Hech narsa ko'rinadigan o'zgarmaydi (frontend hali mock kontentda).
Tekshiruv: make import-content dan keyin bazada 4 fan, kitoblar va mavzular bor; fixture testlari ikki tomonda ham o'tadi. Tayyor mezoni bo'yicha yakunla.
